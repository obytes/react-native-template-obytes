¿Cómo se gestiona el tipo de cambio?

Esta decisión afecta la arquitectura de la base de datos y la experiencia de usuario

A

Manual (Recomendado)

El usuario define el tipo de cambio directamente — por ejemplo, 1 USD = 17.5 MXN. Simple, sin dependencias externas, funciona offline.

B

API de tasas en tiempo real

Se consulta una API (ej. exchangerate-api.com) para obtener tasas actualizadas. Requiere internet y configuración de clave de API.

C

Híbrido

Manual por defecto, con un botón para actualizar desde una API si hay conexión. Más complejo pero más flexible.
