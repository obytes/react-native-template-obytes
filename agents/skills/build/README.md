# Build/Release Skill

## Commands
- `build:version:bump` → Bump version (patch/minor/major) — manual for now
- `build:changelog:add` → Append entry to CHANGELOG.md — manual for now
- `build:prepare` → Run lint, type-check, tests, then create git tag
- `build:ios` → `pnpm build:production:ios`
- `build:android` → `pnpm build:production:android`
